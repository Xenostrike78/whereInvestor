# 💼 WhereInvestor

**WhereInvestor** is a centralized platform built to simplify the discovery and analysis of startup investments. It enables users—entrepreneurs, investors, and researchers—to explore funding patterns, investor portfolios, and startup performance trends across various industries and stages.

Developed using **HTML, CSS, Django, and PostgreSQL**, WhereInvestor is designed to be user-friendly, data-rich, and highly insightful.

---

## 🎯 Key Objectives

To provide an elegant, functional, and intuitive web platform for college project evaluation that enables startups to showcase their ventures and investors to find promising opportunities — all built with **Django**, **HTML/CSS**, and **SQLite**.

---

## 🚀 Features

- ✅ **Elegant Old-Money Aesthetic UI**  
  Formal and luxurious design using glassmorphism, soft gradients, and serif fonts (e.g., Playfair Display, Libre Baskerville).

- 🔐 **User Authentication (Django)**  
  - Secure login/signup system  
  - Distinction between **Startup** and **Investor** user types  
  - Role-based dashboards  

- 👤 **User Profiles (CRUD)**  
  - **Startup Profile**: Industry, Stage, Revenue Model, Funding Needs, History, Document Uploads, Visibility toggle  
  - **Investor Profile**: Investment Preferences, Past Investments, Industry Focus, Pitch Submission Option  

- 🏠 **Landing Page**  
  - Hero section, About, Feature Highlights  
  - Glassmorphic header and footer  
  - CTA buttons linking to Sign Up / Login  

- 📣 **Community Feed**  
  - Startups and Investors can create and view public posts  
  - Displayed in a clean, card-based layout with optional tags  

- 💬 **Discussion Forum**  
  - Category-wise threads (e.g., Trends, Fundraising Tips)  
  - Users can start discussions and reply  

- 🎓 **Mentor Directory**  
  - Static list of mentors with names, fields of expertise, and contact information  

- 📤 **Pitch Uploads**  
  - Startups can upload pitch decks to investor profiles for evaluation  

- 📱 **Mobile-Responsive Design**  
  - Fully usable on desktops, tablets, and smartphones  

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript (minimal)  
- **Backend:** Django (Python)  
- **Database:** SQLite (default Django database)  
- **Styling:** Glassmorphism, serif typography, gradient-based layouts
