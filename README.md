# 💼 WhereInvestor

**WhereInvestor** is a centralized platform built to simplify the discovery and analysis of startup investments. It enables users—entrepreneurs, investors, and researchers—to explore funding patterns, investor portfolios, and startup performance trends across various industries and stages.

Developed using **HTML, CSS, Django, and PostgreSQL**, WhereInvestor is designed to be user-friendly, data-rich, and highly insightful.

---

## 🎯 Key Objectives

- Provide a **comprehensive platform** for exploring startup investments  
- Enable users to **track investors** and their funding history  
- Offer **clear visual insights** into funding trends and sectors  
- Help startups identify **potential investors** based on fit  

---

## 🚀 Features

- ✅ **Professional UI:** Clean layouts with responsive design and modern CSS  
- 🔍 **Investor & Startup Directory:** View detailed profiles and portfolios  
- 📊 **Sector & Stage Analytics:** Visual breakdown of investment activity  
- 📅 **Funding Timeline:** Chronological view of investment patterns  
- 🔐 **User Accounts:**
  - Secure login/signup system
  - Create watchlists *(upcoming)*
  - Save favorite profiles *(upcoming)*

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript (minimal)  
- **Backend:** Django (Python)  
- **Database:** SQLite (default Django database)  
- **Styling:** Custom CSS using modern UI principles  

---

## ✅ Prerequisites

Before running this project on your local machine, make sure you have:

- Python (version 3.8 or above)  
- pip (Python package manager)  
- Git (to clone the repository)  
- A code editor like VS Code (optional but recommended)
